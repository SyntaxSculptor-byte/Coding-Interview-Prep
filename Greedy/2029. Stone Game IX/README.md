# 2029. Stone Game IX

## Topic
Greedy

## Idea
Group stones based on their remainder when divided by 3. The outcome depends only on the counts of remainder-0, remainder-1, and remainder-2 stones. Analyze the parity of remainder-0 stones and determine whether the first player can force a winning sequence using the balance between remainder-1 and remainder-2 groups.

## Complexity

- Time: O(n)
- Space: O(1)
